Personal Portfolio

Live site: https://libanmahdi.vercel.app

Repository: https://github.com/Liban-Mahdi/Personal-Portfolio

Overview

This is a personal portfolio website inspired by the Nintendo Wii interface. It presents my background, skills, and projects using a simple, animated, and responsive layout built with modern web tools.

Tech Stack

React (Vite)

Tailwind CSS

GSAP animations

React-Responsive

Vercel hosting

Features

Wii-style animated interface

Responsive layout across screen sizes

About Me section with animated avatar

Technologies grid with icons

Resume download button

Footer navigation consistent with the overall theme

Setup
git clone https://github.com/Liban-Mahdi/Personal-Portfolio
cd Personal-Portfolio
npm install
npm run dev


Visit http://localhost:5173 to view the site locally.
